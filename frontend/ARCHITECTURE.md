# FinWise AI Agent Architecture

FinWise utilizes a **Hybrid Multi-Model Intelligence Architecture** orchestrated into **four distinct agentic workflows (or "Agents")**:
- **Gemini 2.5 Pro**: Powers high-level macroeconomic strategy, causal risk reasoning, and crisis stress-testing.
- **Gemini 2.5 Flash**: Delivers sub-second response times for interactive sector drill-downs and conversational advisory.
- **Deterministic Math**: Pure quantitative mathematics (zero LLM hallucination) for probabilistic compounding projections.

Each agent is responsible for a specific layer of financial reasoning. Here is the breakdown of the agents and their work:

### 1. The Macro Strategist Agent (`generateWealthPlan`)
* **Where it lives:** `services/geminiService.ts`
* **Its Work:** This is the foundational agent. It takes the user's raw financial profile (income, expenses, capital, risk tolerance, goals) and the simulated BigQuery historical market data. It performs dynamic cashflow reasoning to generate a high-level wealth strategy. 
* **Output:** It strictly allocates wealth across 6 main categories (Gold/Silver, Mutual Funds, Bonds, Fixed Deposit, Stocks, Alternative Growth), calculates a risk score, and generates probabilistic outcome curves (Bull, Base, Bear scenarios) over the user's goal horizon.

### 2. The Sector Analyst Agent (`getCategoryRecommendation`)
* **Where it lives:** `services/geminiService.ts`
* **Its Work:** This agent handles the first level of drill-down. When a user clicks on a main category (e.g., "Stocks" or "Gold/Silver"), this agent analyzes the specific BigQuery data for that category. 
* **Output:** It recommends how to split the money *within* that category (e.g., splitting "Stocks" into 60% Large Cap, 20% Tech, 20% Emerging Markets) and provides 3 key strategic takeaways based on current market conditions.

### 3. The Asset Picker Agent (`getSpecificAssetRecommendations`)
* **Where it lives:** `services/geminiService.ts`
* **Its Work:** This is the deepest level of analysis. When a user clicks on a sub-category (e.g., "Large Cap Stocks"), this agent is triggered.
* **Output:** It generates a highly specific list of the **Top 10 assets/tickers** to invest in. For each asset, it provides the ticker symbol, estimated current price, past performance analysis, future prediction, and a personalized reason why it fits the user's specific risk profile.

### 4. The Conversational Advisor Agent (`sendChatMessage`)
* **Where it lives:** `services/geminiService.ts` (via `initChatSession`)
* **Its Work:** This agent powers the multi-turn chat interface. It is initialized with the context of the user's profile and the exact wealth plan generated by the Macro Strategist.
* **Output:** It acts as an interactive financial planner, allowing the user to ask questions, challenge the AI's logic, or run "what-if" scenarios (e.g., "What if I take a 6-month sabbatical in year 3?"). It maintains conversation history to provide contextual, ongoing advice.
